📡 Setup API Endpoint

Dashboard ini membutuhkan API endpoint untuk membaca data sensor ESP32. Buat file data.json di repository GitHub Anda dengan format:

{
  "temperature": 28.5,
  "humidity": 65.2,
  "gas": 1250,
  "distance": 45.3
}

Atau gunakan ESP32 web server dan ganti API_URL di JavaScript dengan alamat IP ESP32 Anda.
